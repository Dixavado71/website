# DIixWhatsApp — PROMPT MASTER DE DESIGN, LAYOUT E IMPLEMENTAÇÃO

## REFERÊNCIA VISUAL

Você deve criar uma Landing Page para o produto **DIixWhatsApp**, utilizando como referência visual principal o conceito apresentado no design board fornecido junto deste prompt.

A referência apresenta uma interface:

* Dark Cyberpunk
* SaaS Premium
* Futurista
* Tecnológica
* Sombria
* Profissional
* Neon
* Glassmorphism
* Dashboard empresarial
* Automação
* WhatsApp
* E-commerce
* Multi-Tenant

O objetivo NÃO é copiar outra empresa ou outro site.

O objetivo é reproduzir o **conceito visual, composição, hierarquia, atmosfera, linguagem gráfica e sistema de componentes** demonstrados na referência, criando uma identidade própria para DIixWhatsApp.

---

# 1. IDENTIDADE DO PRODUTO

## Nome

**DIixWhatsApp**

## Posicionamento

DIixWhatsApp é uma plataforma SaaS completa para empresas que desejam:

* Criar loja virtual
* Vender pelo WhatsApp
* Automatizar atendimento
* Automatizar vendas
* Gerenciar clientes
* Gerenciar produtos
* Gerenciar pedidos
* Criar fluxos de atendimento
* Centralizar operações
* Trabalhar em ambiente Multi-Tenant
* Escolher planos e pacotes
* Escalar sua operação

O produto deve ser apresentado como uma espécie de:

> **Sistema operacional comercial para empresas modernas.**

Não apresentar o produto simplesmente como "um chatbot de WhatsApp".

A percepção deve ser de uma plataforma SaaS completa.
